# Bollworm Infestation Prediction using Machine Learning

## Objective
Predict weekly bollworm infestation probability for cotton plots using:
- Cumulative Degree Days (CDD)
- Humidity
- Crop Age

## Algorithms Implemented
1. Linear Regression
2. Perceptron
3. Adaline (SGDRegressor approximation)
4. K-Nearest Neighbors (KNN)
5. Logistic Regression (Regularized)
6. Calibrated Logistic Regression (Platt Scaling)

## Dataset
Kaggle:
https://www.kaggle.com/datasets/ravivarmatummala/agriculture-data-ai-based-recommendations

Rename your dataset file as:
data.csv
